### 关键决策（详见 DECISIONS.md）

- **S1-01 FTS5 分词器 = trigram**：实测 SQLite 3.45.1 下 unicode61 的 `MATCH '中文'` 命中 0 条（连续中文被当作单个 token），trigram 命中正常。unicode61 会让 FR-7 对中文用户彻底失效。代价：索引更大、查询至少 3 字符。
- **S1-05 PRAGMA 注入不用 autocommit**：SQLAlchemy 官方示例的 `dbapi_connection.autocommit` 在 **Python 3.11 不存在**（3.12+ 才有）。实测 connect 事件时 `isolation_level=''`，直接执行 PRAGMA 有效。
- **S1-06 窗口参数**：`text_select=True`（默认 False，写作必须可选中）、`private_mode=False`（默认 True 会让 localStorage 不保留，破坏暂存兜底 AC-4）。
- 禁调试：`debug=False` 已足够 —— 源码 `webview/platforms/edgechromium.py:287/288/290` 把快捷键/右键菜单/DevTools 全绑定 `_state['debug']`。
- 错误码映射（报告未定义）已补全：鉴权类 401+1002、签名 401+4004、请求行非法 400+4003、其余 200+code。

### 重要坑

- **Git Bash / MSYS 会转换以 `/` 开头的参数**：`robocopy ... /E` 中的 `/E` 被转成 `E:/` 导致退出码 16。必须加 `MSYS_NO_PATHCONV=1`。
- **不要用 `sqlite3.Connection.executescript()` 执行迁移**：它会先隐式 COMMIT，破坏「多迁移 + 版本号更新在同一事务」的原子性。改为逐条 `execute()`。
- **Windows 的 `os.environ` 会把键名规范化为大写**，测试里断言被清除的变量名时要注意。
- `backend/api/system.py` 若从 `backend.server` 导入会形成循环引用（server → api → system → server）。
