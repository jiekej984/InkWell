## 二、交互能力

| 能力 | 行为 |
|---|---|
| 折叠/展开 | 点卷标题或 ▾；按项目记到 `inkwell:tree:collapsed:<pid>` |
| 右键菜单 | 章节：打开/重命名/章节信息/标记定稿/删除；卷：重命名/新建章/折叠/删除 |
| 章节信息 | 标题、状态（草稿/初稿/定稿）、梗概、目标字数；保存后同步树与编辑器标题 |
| 标记定稿 | 当前章节先保存 → 生成 `milestone` 快照 → `status=final`，树显示「定稿」 |
| 拖拽排序 | 章内/跨卷（`target_volume_id` + `prev_id/next_id`）；卷标题可拖动排序卷 |
| 键盘 | ↑↓/Home/End 选章、←→ 折叠展开、Enter 打开、F2 重命名、Delete 删除 |
| 删卷 | 非空卷三选一：取消 / 移入默认卷 / 一并删除；空卷二次确认 |
| C-04 | 创建首个命名卷且默认卷有章节时，确认后一次性迁入（取消则保持隐藏） |

> 刻意不提供「章节移入默认卷」菜单项：默认卷在树中隐藏，移入会让章节不可达；
> 仅在删卷时允许移入（S3-02）。
