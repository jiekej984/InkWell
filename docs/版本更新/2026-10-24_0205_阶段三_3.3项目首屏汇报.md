## 二、卡片与首屏三态

| 能力 | 行为 |
|---|---|
| 封面 | 有图走 `/files/` 签名 URL；缺图或加载失败回退「书名首字 + 默认封面 / 封面缺失」（FR-1.8） |
| 状态徽标 | 连载中 / 已暂停 / 已完结；底色 `--accent-soft` / `--sidebar` / `--success-soft`，文字统一 `--text`（AA） |
| 进度 | 仅设了目标字数时显示（FR-1.3）；不足 1% 显示「<1%」 |
| 最近打开 | `last_opened_at`，为空回退 `updated_at`；「刚刚 / N 分钟前 / 今天 HH:MM / 昨天 HH:MM / MM-DD / YYYY-MM-DD」 |
| 打开方式 | 整卡 `role="button"`（Enter / 空格）+ 「打开 / 设置」按钮常显 |
| 暂存横幅 | 每条暂存一个按钮直达对应作品；项目已进回收站则置灰并说明 |
| 骨架态 | 请求返回前 3 张占位卡 + `aria-busy`，`prefers-reduced-motion` 下停动画 |
| 出错态 | 红色描边 + 具体原因 + 重试，不静默留白 |
| 空态 | 虚线框 + 「还没有作品」+ 说明 + 主 CTA「新建第一本书」 |

## 三、首启引导（C-09）

```
新建项目成功 → GET /projects/{id}/volumes 取默认卷 → POST 建「第一章」
            → openWriter(id)（内部 await 完章节加载）
            → focusEditor()：确认 contenteditable 后聚焦，光标落末尾
```

- **聚焦时序**：严格在章节加载完成之后；依据 `阶段三_IME验证记录.md` §二
  （章节未就绪时聚焦会让首次组合串被丢弃）。`focusEditor()` 自身再判一次就绪，
  未就绪返回 `false`，调用方只记 warn、不重试。
- **失败降级**：建章失败不阻断，仍进入写作页，用户可手动新建。
- **只在新项目路径触发**：编辑已有项目、从导航返回列表都不会自动建章。

## 五、决策与取舍

1. **不采用「hover 才露出按钮」**（S3-06 ④）
   初版实现后截图显示：按钮隐去使卡片底部出现无法解释的空隙，主操作不可发现，
   键盘/触屏用户也看不到。改为**常显按钮 + hover 强调**（卡片抬升、描边加深）。
2. **最近打开写在 #3 详情里**
   详情是「打开项目」的唯一入口（写作页 `openWriter` 先取详情），无需新增接口；
   只写 `last_opened_at`，列表仍按 `updated_at` 排序。
3. **骨架态是行为变化**
   列表每次刷新都会先清空再渲染，任何「回到列表」后立即查询旧卡片的脚本都会拿到
   `null`。本次已修正 `window_smoke.py` 与 `capture_ui.py`，后续新增脚本需同样先等卡片就位。
