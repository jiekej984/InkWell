## 三、字体：这一轮把 §7.2 的首选字体真正接上了（**全站视觉变化**）

`§7.2` 写的是「思源黑体 / 苹方 / 微软雅黑；西文 Inter」，3.1 的 token 栈里只有
`Source Han Sans SC` 这个家族名。本机实测安装的是 **`思源黑体 CN`**（家族名
`Source Han Sans CN`），所以 `Source Han Sans SC` 一直没命中，中文实际渲染的是微软雅黑。

本轮在栈里补上实际家族名后，本机中文**从微软雅黑切到思源黑体 CN**：

- 正文字形、字宽、字重都变了，`after_3_4` 与 `after_3_3` 的像素差因此在**所有页面**都有
  1.4%～5.7%（详见 §六），但**没有布局位移**：第一张卡片左边框两版都是 `x=173`，
  编辑器内容左边界两版都是 `x=407`（见 §五）。
- 未装思源黑体的机器会继续回落到苹方 / 微软雅黑，行为不变（`font-family` 逐项回落）。
- 取舍：这是 §7.2 的首选字体，属于「按规范校准」，不是顺手改风格；同时它让 3.4 的
  像素对照不能只拿编辑器页面看，故在 §六 单列说明。

## 四、容量提示（FR-3.9 / 回归 20）

```
本章字数 ──┬─ < 50,000 ─→ ok     不显示
           ├─ ≥ 50,000 ─→ warn   本章 5.2 万字 · 已超 5 万字建议上限
           └─ ≥ 80,000 ─→ split  本章 8.2 万字 · 建议拆章（不影响保存）
```

- **两档阈值都有出处**：5 万字 = §2.4 NFR-P2 / AC-1「单章 ≤5 万字」的承诺范围；
  8 万字 = §8.1 回归 20「打开 8 万字超长章节给出拆分提示且不崩溃」。
- **只提示、不阻断**：不弹窗、不禁用编辑器、不改数据、不拦截保存；`title` 里给出完整解释。
  窗口冒烟在 9 万字章节里继续输入并等到了「已保存 + 版本号 +1」，证明保存链路不受影响。
- **两档都实测过**：split 档由回归套件覆盖（9 万字 → `is-split`）；warn 档另用一次性脚本
  在真实窗口核查过——52,440 字章节渲染出「本章 5.2 万字 · 已超 5 万字建议上限」，
  `class="statusbar__chip is-warn"`（脚本与截图留在 `_local/`，不入库）。
- **放在状态栏**而不是编辑器上方：不挤压正文行宽；`role="status"` 让它被读屏软件播报，
  颜色（描边）+ 文案（「建议拆章」）双编码，不单靠颜色。
- 判定与文案是纯函数（`capacity.js`），11 条 Node 用例覆盖阈值边界、脏输入、单调性。

## 七、决策与取舍

1. **段间距取 0**（`--paragraph-gap`）
   中文小说用「首行缩进 2 字符」断段，段间再加空隙会让长章节读起来更散；与 §7.2
   「安静、克制」的取向一致。要改版式只改这一个 token。
2. **缩进豁免必须逐类显式清零**
   `text-indent` 会继承：只写 `p { text-indent: 2em }` 时，列表项 / 引用 / 代码块都可能被
   「串味」。本轮把标题（h1~h6）、`ol/ul/li`、`blockquote`、`pre`、`.ql-code-block-container`
   一起写成 `text-indent: 0`，并让 smoke 逐类断言。
3. **图片不跟着缩进**
   独占一行的图片段落 `text-indent: 0`，图片 `display:block; margin: auto` 居中——
   否则图片会被 2em 缩进推右 34px，还会因为 `max-width:100%` 撑出横向滚动条。
4. **占位提示重做定位**
   Quill 的 `.ql-blank::before` 原本相对 `.ql-container` 定位，窗口一宽就会飘到正文列左边；
   改为 `.ql-editor { position: relative }` + `left: 24px / text-indent: 34px`，与首行正文对齐
   （像素实测同列）。
5. **代码块与引用改成浅色 token**
   Quill 默认代码块是深底 `#23241f`（浅色主题里像一块黑板）、引用竖线是硬编码 `#ccc`、
   链接与工具栏悬停是 `#06c` 蓝——全部换成 `--sidebar` / `--border` / `--accent-strong`。
6. **选中色加权**
   原 `--accent-soft`（#F0EBE3）在 `--bg`（#FAF9F7）上几乎看不出选中范围，改为
   `--accent` 24% 叠加；文字仍是 `--text`（≈11:1），选中范围一眼可辨。
7. **容量提示放状态栏，且永不阻断**
   见 §四。提示文案由纯函数产出，状态栏只负责显示/隐藏与档位类名。
