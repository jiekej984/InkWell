## 二、失败态与导出（C-03 的核心）

保存失败时**库内正文是旧的**，导出库内正文没有意义。因此 #50 允许前端把编辑器当前正文
（`content_html`）一并提交：

```
POST /api/chapters/{cid}/export
{"format": "txt", "title": "当前标题", "content_html": "<p>……</p>"}
```

- 服务端对 `content_html` 走**与保存同一条链路**（签名图片路径还原 → 白名单消毒 → 纯文本/字数），
  只用来生成文件，**不写库**；字数因此与「如果保存成功」的口径一致；
- 不传 `content_html` 时导出库内正文，字数取章节缓存值（接口对脚本/未来入口同样可用）；
- 输出 `<数据目录>/exports/{书名}_{章节标题}_{YYYYMMDD_HHMMSS}.{txt|md}`，沿用整本导出的
  安全文件名（非法字符替换、60 字截断、同秒去重）与 BR-7（`.tmp` + `os.replace`）；
- 返回 `relpath` / `path` / `word_count` / `source`（`client` / `stored`）/ `empty`；
- **同步执行**：单章体量 ≤8MB 入参，不套长任务（避免为一次应急导出多一层轮询）。

状态栏提示为「已导出 文件名（exports/…）」，悬停显示完整绝对路径；「打开数据目录」的桥接入口
按 C-07 归 3.6（P9 设置页），届时可把该提示升级为「打开所在目录」。

## 三、三态与无障碍

```text
saved    ✓  已保存 23:45        绿描边 + --success-soft + 绿色图标
saving   ◌  保存中…            灰描边 + --sidebar + 呼吸动画（prefers-reduced-motion 关闭）
failed   ⚠  保存失败，已本地暂存  红描边 + --danger-soft + 红色图标 + [重试] [导出本章]
conflict ⚠  版本冲突，已本地暂存  同上 + [刷新并恢复] [导出本章]
```

- **文字颜色统一 `--text`**：实测 `--success` on `--success-soft` = **4.37:1**、
  `--danger` on `--danger-soft` = **4.10:1**，作 12px 正文不达 AA（与 S3-01 同一结论）；
  颜色编码改由**描边 + 图标着色 + 底色**承担，文字保持 13.46:1；
- 图标 `aria-hidden="true"`，文案独立 `role="status" aria-live="polite"`，状态变化会被读屏播报；
- 与保存无关的提示（标题已保存 / 已回滚 / 导出结果）走状态栏 `#status-note` 独立通道，5 秒自动消失，
  **不覆盖三态**——否则「已保存 23:45」会被一句「标题已保存」顶掉；
- 失败/冲突态下继续输入**不**把状态改回「未保存」：否则问题被掩盖，动作按钮也会消失。
