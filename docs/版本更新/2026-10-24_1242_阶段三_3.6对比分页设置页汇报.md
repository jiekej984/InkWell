## 二、P5 差异对比的算法与边界

- **行 = 非空段落**：服务端 `extract_text` 已把正文归一为「段落用换行分隔」的纯文本；
  版本正文在浏览器侧用 `htmlToText()` 还原（`<br>` → 换行、块级闭合标签 → 换行、标签剥离、实体解码）；
  当前正文直接取 Quill `getText()`，**未保存的编辑也会进入对比**。
- **LCS 动态规划 + 回溯**，输出 `equal / add / del`；`add` = 当前正文有、旧版本没有。
- **双重上限保护**（界面绝不卡死）：
  - 任一侧 > **5 万码点**（按码点计数，emoji 算 1 个）→ `tooLarge`；
  - 行数乘积 > **400 万**（病态输入，如 5 万行单字）→ `tooLarge`。
  - 两种情况都只显示提示「差异对比已省略，可切到内容预览」，不渲染行。
- **折叠**：连续相同行 > 7 时保留上下文各 3 行，中间显示「⋯ 相同的 N 行 ⋯」。
- **渲染**：增行绿底、删行红底、行首 `+ / − / 空格` 三个符号；文字统一 `--text`
  （`--success` / `--danger` 作小字正文在浅底上只有 4.37 / 4.10:1，只用在背景与符号上）。

## 三、P6 分页

- 每页 **20** 条，`加载更多` 用同一查询条件追加（`q / scope / project_id` 保留在状态里，
  输入框中途改动不会污染已发起的分页）。
- 状态行显示「共 N 条（模糊匹配）· 已显示 M」；按钮在 `已显示 ≥ total` 或加载中隐藏。
- `page_limited=true`（单侧 1000 条窗口被截断）时，翻到 `page*page_size ≥ 1000` 即停止，
  并显示后端 hint「结果过多，仅支持前 1000 条以内分页；请加长搜索词」。
- 三态：加载骨架、空态「没有找到匹配内容。」、错误态带「重试」；**加载更多失败保留已显示结果**，
  按钮重新出现可直接再点。

## 四、P9 与 #51 / #52

| 区域 | 内容 |
|---|---|
| 数据与磁盘 | 数据目录、数据库路径与体积（含 WAL）、schema 版本与期望值、磁盘可用/总量、内容计数、快照/暂存/备份数、自检结果与时间 |
| 维护工具 | 重建全文索引（#42）、重算字数（#43）—— 长任务 500ms 轮询；清理过期快照（#51）；数据库自检（#52） |
| 诊断与目录 | 下载诊断包（#49，Blob）；打开数据目录（桥接 `open_data_dir()`） |
| 字数口径 | 只读说明（C-07：不提供口径开关，归 V1.1） |

- **#51 为同步接口**：逐章执行 D-04 保留策略（最近 30 条 + 每日首条 30 天），只是 SQL；
  800 章量级几十毫秒，套长任务反而多一层轮询。manual / milestone / restore 不动。
- **#52 默认 `quick_check`**（打开设置页即刷新）；「数据库自检」按钮走 `?full=1` 的完整
  `integrity_check`。返回计数/体积/磁盘信息，**不含正文**。
- **`open_data_dir()`**：`os.startfile(data_dir)`（Windows），只打开固定目录，失败返回
  `{ok:false, error}` 由页面提示；e2e 的 `TokenApi` 提供同名桩，不真的拉起资源管理器。
- **刷新信息不覆盖动作结果**：维护/清理成功后先给结果文案，再 `refreshIntegrity({silent:true})`
  静默刷新信息区（否则「已清理 N 条」会被「自检通过」瞬间顶掉——这是本轮 e2e 抓到的真实缺陷）。
