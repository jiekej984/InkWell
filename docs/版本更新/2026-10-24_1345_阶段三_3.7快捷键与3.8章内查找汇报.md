## 三、门禁与边界（S3-03 / C-06）

- **IME**：`event.isComposing === true` 或 `keyCode === 229` 直接放行，不 `preventDefault`、不触发动作（回归 24 的 CDP 组合事实验证）。
- **对话框**：`document.querySelector('dialog[open]')` 存在时全部跳过，原生 Esc 关闭不受影响。
- **输入框**：`input` / `textarea` / `select` / `contenteditable` 默认不触发；**Quill 正文例外**——它是写作主输入面，若按输入框屏蔽，写作时 Ctrl+N/S/F 会全部失效（这是本轮定下的边界，已写入 C-06 / S3-12）。
- **长按**：`event.repeat === true` 默认忽略，避免按住 Ctrl+S 连发快照（单测覆盖）。
- **Win 键**：`metaKey` 单独成段，不会命中应用的 Ctrl 组合。
- **与 WebView2 默认行为隔离**：命中即 `preventDefault`；**保留键兜底**——`Ctrl+F / N / S` 即使被门禁拦下（输入框 / 对话框 / IME 组合），也 `preventDefault`，避免落回 WebView2 的浏览器查找 / 新窗口 / 「保存网页」。
- **已实测**：Ctrl+F 打开的是应用查找条，不是浏览器查找；Ctrl+S 不再触发「保存网页」。

## 四、章内查找（3.8 / 回归 25）

- **匹配**：按**文本节点**扫描（跨段落短语不命中，符合「章内查找」常规语义）；UTF-16 下标直接映射 DOM `Range`，中文 / emoji 都不拆代理对；正则元字符按字面量转义；查询上限 200 字。
- **高亮**：`CSS.highlights` + `::highlight(inkwell-find / inkwell-find-current)`；**实测 WebView2 155 支持**（V-02 对 3.8 关闭，`highlight: 2` 见 manifest）。不支持时降级 Selection + `scrollIntoView`。
- **交互**：输入即时定位；`n/N`；Enter / Shift+Enter 与「上一个 / 下一个」；区分大小写；Esc 关闭；打开时若编辑器内有非空选区（≤80 字）则预填。
- **不修改正文**：只建 Range 与高亮，不触发 Quill `text-change`；冒烟对 `innerText` 前后逐字比对。
- **联动**：正文变化时自动重扫；切章 / 离开写作页自动关闭。
