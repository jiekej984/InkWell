## 四、给 5.4（角色列表 + 卡片）的注意点

1. **前端拿枚举一律走后端**：`GET /api/projects/{pid}/characters/meta`，不要在前端写死 20 类标签。
2. **字段级保存**用 `PATCH /api/characters/{cid}`，只传改动的字段；返回的是完整详情，可直接刷新卡片。
3. **别名**用 `PUT .../aliases` 整体替换；冲突返回 `1001` 且 message 里带占用人名，前端可直接展示；需要强制时加 `force: true`。
4. **详情接口一次带全**：别名 / 字段 / 关系 / 组织身份，卡片页不必再发多个请求。
5. **立绘上传**是 multipart：`POST /api/characters/{cid}/avatar`，返回 `{path,url,size}`；`url` 已带签名，30 分钟有效，过期用 `/api/files/sign` 续签。
6. **列表分页**：`page` 从 1 开始、`page_size` ≤200；返回 `total`，前端按需做「加载更多」。
