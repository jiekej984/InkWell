## 二、实现过程中的自查发现（8 项）

| # | 发现 | 处置 |
|---|---|---|
| **H1** | 阵营关系「目标阵营」下拉没有占位项，第一次截图里是一块空白 | 加 `选择阵营` 占位（`allLabel`），截图复核 |
| **H2** | 删根组织时把「上移一级」整行隐藏了，而任务要求是**置灰**——用户看不到为什么不能选 | 改为 `disabled` 可见 + `title` 说明「顶层组织没有上级可挂」 |
| **H3** | 成员「主组织」复选框取消勾选时不发请求，界面看着取消、刷新又回来 | 改为双向 `PATCH {is_primary: checked}`（允许一个角色暂时没有主组织） |
| **H4** | 改组织阵营/新建/删除组织后，阵营卡片上的「N 组织」计数不更新 | 这三处操作后重拉 `factions` |
| **H5** | 任务写「右键升一级 / 移到」，实际用「升一级」按钮 + 拖拽替代 | 记录取舍：右键菜单在 5.8 画布交互里更自然，这里先不做，功能不等价缺失 |
| **H6** | 成员的「生效章」下拉直接拉平卷章树，几百章时会很长、不可搜索 | 记录待优化：与 C-20 的「章节下拉可搜索」一起做（关系表单在 5.6） |
| **H7** | 组织树的折叠状态在重载后丢失（重拉树会重建 DOM） | 用 `state.collapsed` 集合保留，跨刷新仍记得 |
| **H8** | Tab 从占位页切真实面板后，5.4 的 `.is-placeholder` CSS 与节点残留 | 删除占位节点与样式，改为 `is-tab-characters/organizations/factions` 三态类 |

## 四、给 5.6（关系编辑 + 小面板）的注意点

1. **`getCurrentProject()` 已导出**：角色页当前项目可直接取，关系面板不必再传参。
2. **成员表已用「章节下拉」**：`chapterOptions()` 在 `organizations.js` 里，5.6 的关系表单若要可搜索，建议抽成公共组件（当前是 `<select>`，几百章要改成输入过滤）。

4. **组织身份数据已在**：`GET /characters/{cid}` 的 `memberships` 已返回组织名/职位/主组织/隐蔽，小面板直接渲染即可。
5. **成员/关系保存都是「改完即存」**：小面板里的关系也照此办理，不引入整卡保存。
6. **Tab 事件**：`inkwell:character-tab` 只在切到组织/阵营时触发；如果 5.6 需要「切回角色时刷新小面板」，可监听同一事件并判断 tab。
