## 二、实现过程中的自查发现（8 项）

| # | 发现 | 处置 |
|---|---|---|
| **R1** | 右栏跑到了卡片**下方**而不是右侧——`.writer__body` 本身是 `flex-direction: column`，只改 `display` 不够 | 显式 `flex-direction: row`（截图发现） |
| **R2** | 320px 宽度里「起始章 / 结束章」溢出，结束章被裁掉 | 表单控件 `min-width: 0` + `width: 100%` |
| **R3** | 卡片变窄后底部出现横向滚动条 | `.character-card { overflow-x: hidden }` + 字段行允许换行 |
| **R4** | 新建 / 改名 / 删除角色后，关系表单的角色下拉还是旧列表（缓存按项目 ID 判定） | 导出 `invalidateRelationSupport()`，三个入口调用 |
| **R5** | 从组织页切回角色页，右侧「组织身份」还是旧数据 | 监听 `inkwell:character-tab`，切回时重拉角色详情 |
| **R6** | 任务要求章节下拉可搜索；原生 `<select>` 不能搜索 | 关系表单改成「输入框 + 建议列表」；**组织成员表仍是原生 select**，与 H6 一起留待后续统一 |
| **R7** | 「在图中查看」在关系图（5.7）之前没有落点 | 按钮保留但禁用，标注「下一步开放」 |
| **R8** | 关系行最初用内联 `style` 撑样式，难维护 | 改为 `.relation-row__main` CSS 类 |

## 四、给 5.7（人物关系图大画布）的注意点

1. **「在图中查看」按钮已就位**（`#open-graph-character`），5.7 去掉 `disabled` 并实现跳转，建议传 `center_id` 打开画布并聚焦当前角色。
2. **图数据接口已可用**：`GET /projects/{pid}/graph?mode=character&center_id=&depth=`，返回 `nodes/edges/groups/truncated`，与 5.2/5.3 一致。
3. **关系颜色/分组映射**：`character_meta.RELATION_FAMILIES` 五色系可直接复用，前端不必再算。
4. **章节可搜索下拉**已实现 `makePicker`（relations.js 内部），5.7 若要在画布筛选里选章节，建议抽到公共模块。
5. **布局坐标**：`#80/#81` 已通，`save_layout` 按模式合并；画布拖拽结束保存时记得带 `updated_at`（否则 3002）。
6. **窄窗口**：右栏固定 320px，5.7 的画布页建议独立视图或全屏面板，不要塞进这个两栏。
