## 四、给 5.8（组织树 + 阵营全景）的注意点

1. **画布与数据已就绪**：`#64` 支持 `mode=organization|faction`，`graph.js` 目前只做 `character`；5.8 加模式切换时复用同一套 SVG/缩放/拖拽。
2. **布局按模式隔离**：`#81` 的 payload 是 `{character, organization, faction}` 三个命名空间，保存时**只传当前模式**即可，不会清掉另外两个。
3. **组织节点尺寸不同**：组织是圆角矩形卡（带名称/人数），现在只有圆点；5.8 需要单独的节点渲染分支。
4. **力导向可复用**：组织树用层级布局（RT），阵营用分组簇，别硬套 FR。
5. **右键菜单可扩展**：现有三项对人物模式够用，组织/阵营模式建议加「展开成员 / 查看组织」。
6. **隐藏集合是会话级**：切模式时建议清空，避免人物隐藏影响组织视图。
