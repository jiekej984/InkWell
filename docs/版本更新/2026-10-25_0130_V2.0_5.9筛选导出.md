## 三、实现过程中的自查发现（9 项）

| # | 发现 | 处置 |
|---|---|---|
| **S1** | 导出首版**节点全是黑块、中文不可见**：内联样式把原 `fill: var(--org-fill-3)` 也带进 SVG，脱离页面后 CSS 变量失效，黑色覆盖了正确颜色 | 内联时**只写计算后的值**（覆盖原 style），并补 `display / visibility / stroke-linecap`；导出实样已落盘复核 |
| **S2** | 关系文字在导出图里变成衬线体，与界面不一致 | `.graph-edge-label` 显式指定 `font-family: var(--font-ui)` |
| **S3** | 筛选抽屉浮在画布右侧，会遮住部分节点 | 有意的浮层，关闭即恢复；未做贴边抽屉动画（低优先） |
| **S4** | 模式切换后筛选条件仍保留，但组织/阵营模式不认章节与失效关系 | 按模式禁用对应控件 + 抽屉底部提示 |
| **S5** | 「重置」后还要再点「应用」多一步 | 重置即应用并关闭抽屉 |
| **S6** | 「锁定布局」只锁节点拖动与重排，不锁缩放/平移 | 有意：看细节还需要缩放；文案写「锁定后节点不能拖动」 |
| **S7** | 锁定状态是会话级，没有落库 | 记录：布局接口只有坐标，没有锁字段；如需要放 5.10 加 |
| **S8** | 导出的是**当前视口**（含缩放平移），不是全图自动适配 | 记录：所见即所得；全图导出可在 5.10 加一个选项 |
| **S9** | 性能脚本不含 DOM 首绘，不能完全代表 AC-21 | 脚本输出已注明；人工验收补充拖拽流畅度 |
