**数据覆盖点**

- **角色**：主角/女主/反派/重要配角/龙套五种定位；存活/失踪状态；别名、自定义字段（灵根、境界、本命剑、算盘、相机等）
- **组织**：单层与两层树（帝国→玄甲卫/星枢院；港务局→缉私队；星海盟商会→拾光号）；首领、简介、颜色
- **成员**：职位、主组织、隐蔽身份（沈砚舟在青帮是暗子；裴玄枢在归墟教是暗子）
- **阵营**：名称、颜色、简介；阵营间结盟/敌对/中立
- **关系**：20 类中的师徒、恋人、血仇、敌对、竞争、婚约、父女、兄妹、主仆、庇护、线人等；双向/单向、隐秘、**带生效章的失效关系**
- **章节**：两卷结构、正文段落、字数统计
- **文档**：世界观（《九域星图》《雾港地理志》）与势力（《归墟教义》《青帮家规》）

适合用来试：

1. 角色卡右侧关系面板（分组、隐秘 🔒、失效灰显）
2. 关系图三种模式（人物力导向 / 组织层级树 / 阵营全景）
3. 筛选抽屉（按阵营「正道」筛出人物子集；「显示失效关系」能看到《天穹之外》里顾长庚与陆青野的旧竞争关系）
4. 关系文字开关（色觉无障碍）
5. 回收站联动与删除确认（书本身、角色、组织）

## 二、备份与回滚

生成前脚本自动备份到：

```
data/backups/seed-demo-20261025-014152.db
```

回滚（先关掉应用）：

```powershell
Copy-Item data\backups\seed-demo-20261025-014152.db data\inkwell.db -Force
Remove-Item data\inkwell.db-wal, data\inkwell.db-shm -ErrorAction SilentlyContinue
```

## 三、重新生成 / 只生成一本

```powershell
# 写入默认书库（已有同名书会跳过）
.venv\Scripts\python.exe scripts/seed_demo_novels.py --data-dir data

# 只生成一本
.venv\Scripts\python.exe scripts/seed_demo_novels.py --only wugang

# 先写到临时目录看效果
.venv\Scripts\python.exe scripts/seed_demo_novels.py --data-dir .demo-data
```

需要删掉示例书时，在应用内删除即可（进回收站），或直接删掉对应项目行；脚本不会自动清理。
