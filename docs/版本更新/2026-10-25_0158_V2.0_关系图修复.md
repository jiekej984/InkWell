# V2.0 关系图体验修复（用户反馈）

> **时点**：2026-10-25 01:58
> **触发**：用户提供两张真实截图（《雾港旧事》《天穹之外》），反馈 5 个问题
> **状态**：已修复；**98 JS passed**、真实示例书 18 节点验证通过
> **验证脚本**：`tests/e2e/capture_demo_graph.py`（复制真实书库到临时目录，不动原库）

---

## 一、反馈与修复

### 1. 拖拽「空气墙」

**现象**：节点拖到画布外围会被卡住，像有一圈隐形墙；角色多时尤其难受。

**原因**：`onPointerMove` 里把坐标硬夹在 `20 ~ 1200-20 / 800-20`。

**修复**：去掉拖拽坐标夹取，节点可以拖到任意位置；`适应窗口` 会按实际包围盒重新缩放。同时把滚轮缩放下限从 0.25 放宽到 **0.08**（角色多时可以缩得更远看全局）。

**验证**：自动化拖拽记录 `translate(528,301) → translate(1352,825)`，已超过旧边界；再拖回中心 `translate(614,383)`，双向都自由。

### 2. 左键双击打不开角色卡

**原因**：节点 `pointerdown` 里调用了 `preventDefault()`，浏览器不再合成 `click / dblclick`，挂在 `svg` 上的 `dblclick` 永远不会触发。

**修复**：在 `pointerup` 里自己做双击判定（同一节点、360ms 内两次），直接调用 `openCharacterCard`；原生 `dblclick` 保留作兜底，并用时间戳避免重复打开。

**验证**：CDP 真实双击「顾长庚」节点 → 角色页打开且 `#character-name` 为「顾长庚」。

### 3. 节点压在别的连线上

**现象**：顾长庚—白霜的连线正好穿过「小灯」，不拖开看不清。

**修复**：新增纯函数 `separateNodes()`，布局结束后做松弛：

- 节点之间保持最小间距
- 节点从**与自己无关**的连线旁挪开（按点到线段距离）
- `pinned`（手动拖过的）节点不动，只推别人

在力导向结束、以及加载已保存布局时各跑一次。另外人物模式的边改成**轻微弧线**（按边 id 稳定散列决定弯向），减少多条线重叠时的粘连感。

### 4. 阵营卡片挡住关系线

**修复**：阵营模式分层渲染——阵营底色画在**边下层**，文字和透明命中区画在**上层**。关系线从卡片上穿过，文字加背景描边保证可读。

顺带修了 **阵营卡「N 个组织」恒为 0** 的问题：阵营节点本身不带 `member_ids`，改为用可见组织按 `faction_id` 统计。

### 5. 《天穹之外》24 条关系太乱

**修复**：初始布局从「随机圆周」改为 **BFS 同心环**——度数最高的角色居中，一跳、二跳、三跳一圈圈向外，断开的角色排外圈；再做力导向与上述松弛。边标签也沿边错开位置（0.38~0.62），不再全部挤在中点。

**旧布局兼容**：加载时如果保存的布局里**没有任何 pinned 节点**，视为自动布局，直接按新算法重算；只要有一个手动拖拽过的节点，就完整保留用户摆位。

## 三、说明与后续

1. 真实书库的旧图布局**没有手改**；下次打开《天穹之外》会自动按新算法重算（因为没有 pinned 节点）。
2. 如果自己拖过位置，布局会保留，可能仍是旧的疏密；点一次「重排」即可。
3. 关系特别多时，仍建议用「在图中查看」聚焦某个人或筛选阵营，力导向只能缓解、不能消除交叉。
4. 后续可做：边标签碰撞避让、按社区分组着色、导出全图。
