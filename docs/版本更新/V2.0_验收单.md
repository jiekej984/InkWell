## 四、偏差与延后

| 项 | 说明 | 归属 |
|---|---|---|
| AC-19「卧底成员虚线」 | 组织模式图数据只有组织节点/组织关系，没有成员边；卧底身份在角色卡与成员表已可查。补成员边会显著增加 5.2 图接口复杂度，收益低 | V2.1（若需要） |
| 组织树 50 节点性能 | `treeLayout` 是确定性 O(n) 分层，6 组织示例正常；未单独造 50 节点压测 | V2.1 回归 |
| 出场检索（FR-8.23） | 任务清单标 P2、可延至 V2.1；本期未实现 | V2.1 |
| 项目删除与 V2 数据 | 项目软删除不级联角色/组织/阵营（它们不随项目进回收站）；项目恢复后数据原样保留，物理清空项目时外键级联删除 | 记录为当前行为 |
| 图布局自动升级 | 只有「无手动拖拽」的旧自动布局会按新算法重算；手动摆位永久保留 | 已按用户确认规则实现 |

## 五、人工验收建议（5 分钟）

1. 打开《天穹之外》→ 角色库 → 关系图：切人物/组织/阵营，确认卡片不重叠、线不被遮挡、同姓显示全名
2. 拖动一个节点 → 切换模式再切回 → 位置仍在
3. 筛选「天枢帝国」相关阵营/组织 → 应用 → 重置
4. 导出 PNG → 打开图片确认中文与图例
5. 删除一个角色 → 打开回收站 → 恢复 → 角色回到列表（别名一并恢复）
