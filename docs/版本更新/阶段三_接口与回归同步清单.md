**#52 行为补充（3.9 修订）**：

- 默认 `quick_check`（毫秒级，打开 P9 页即刷新），`?full=1` 执行完整 `PRAGMA integrity_check`；
- **完整自检使用一次性独立连接**，不复用连接池（原因：FTS5 的索引结构缓存是 per-connection 的，
  `#42 重建索引` 后池内旧连接会误报 `malformed inverted index`；详见 `docs/故障排查.md` 与 `DECISIONS.md` S3-15）；
- `#42 rebuild-fts` 提交后回收连接池（`Database.recycle_connections()`），从源头不留过期结构。

**#22 行为语义补充（3.9 修订，**契约易错点**）**：

- `POST /volumes/{vid}/chapters/reorder`：**路径 `vid` 是源卷**，目标卷放在 body 的 `target_volume_id`；
- 同卷排序时 `target_volume_id` 可省略；跨卷移动时必须同时给出源卷（路径）与目标卷（body）；
- 3.9 修复了一个前端缺陷：`sidebar.js` 原先在路径里传了**目标卷**，同卷排序碰巧成立，
  跨卷拖拽会被后端以 1001「章节不属于该卷」拒绝（回归 21 的跨卷分支因此一直没被覆盖到）。

| 缩放 | 视口宽 | 横向溢出 | 正文 `max-width` |
|---|---|---|---|

结论：三档均无横向滚动、侧栏与状态栏常驻可见；正文行宽上限不随缩放变化（中文阅读行长稳定）。

### 3.3 键盘（V-06 结论）

- **Tab 顺序**（写作页实测 36 站）：顶栏（返回 → 搜索 → 设置 → 备份 → 回收站）→ 侧栏（＋卷 →
  卷折叠 → ＋章 → 各章）→ ＋章 → 标题输入 → 存为版本 → 版本 → 设定 → 保存 → 工具栏（19 个按钮 +
  标题选择器）→ 正文编辑器；**全部站点都是可交互元素**，无「Tab 掉进普通 div」。
- **焦点可见**：键盘聚焦时描边 2px（`:focus-visible`），实测顶栏 / 侧栏 / 树节点均命中。
- **对话框**（原生 `<dialog>` + `showModal()`）：打开后焦点落在首个输入框；Tab 四次不逃逸；
  Esc 关闭；**关闭后焦点归还触发按钮**（三条都是原生行为，本轮验证成立，未额外写 JS 陷阱）。
- **大纲树**：↑/↓ 移动、Home/End 到首尾、← 折叠 / → 展开、F2 改名、Delete 删除。
  **3.9 修复**：← 折叠后章节容器 `display:none`，焦点原本会掉到 `body`（键盘用户无法再展开）——
  改为把焦点交给该卷的折叠按钮；卷折叠按钮补 ←/→ 折叠展开，↓ 先展开再进入首章。
