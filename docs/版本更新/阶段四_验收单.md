## 二、性能实测（AC-1 / AC-2 / AC-3 / AC-10）

测量对象是**冻结产物本身**（含 PyInstaller 引导与 WebView2 初始化）；数据规模 20 卷 × 100 章 + 5 万字章 = **505 万字**（AC-10 要求 10 万字，高 50 倍）。

| 项 | 目标 | 实测 | 结论 |
|---|---|---|---|
| AC-2 冷启动（进程起 → 项目列表可交互，5 次中位数） | ≤3s | **978 ms**（975 / 975 / 978 / 982 / 1106） | ☑ |
| AC-3 打开 5 万字章节到可编辑 | ≤1s | **97 ms** | ☑ |
| AC-10 检索（后端，10 次 p50） | ≤1s | **14.2 ms**（p95 31.5 ms，章节 + 设定文档都命中） | ☑ |
| AC-10 检索（UI：输入 → 首条命中） | ≤1s | **55 ms** | ☑ |
| AC-1 大纲树（2001 章全量渲染） | 不卡（M5 参考 800 章 ≤1s） | **492 ms** | ☑ |
| §12.1 导出 500 万字 | ≤60s（假设） | **310.8 ms**（5,050,000 字 / 15.2MB / 2001 章） | ☑ |

**内存（NFR-P6，口径见 S4-01）**：空闲态私有 **284.0 MB ≤ 300 MB → 达标**；重负载私有 384.2 MB 登记为参考值；工作集求和（上界）454~536 MB 不作判定。

> 原始数据：`docs/版本更新/阶段四_性能实测.json`；明细与偏差分析：`2026-10-24_2019_阶段四_4.4性能实测汇报.md`。
> 环境：AMD Ryzen 7 8845H（8C16T）/ 15.3GB / SSD / Windows 10.0.22631 —— 比 D-06 的「中位机 i5-10代/8G/SSD」更好，
> 因此数字对目标机器偏乐观，但最短的一项（AC-2）仍有 3 倍余量。

## 四、本机无法自动化、需要人工/外部确认的项

| # | 项 | 怎么验 | 期望 | 结果 |

| M1 | **干净机器可运行**（4.1 的验收原文） | 找一台**未装过 Python / 未跑过本项目**的 Windows 10/11 x64：解压 zip → 双击 `Inkwell.exe` → 新建项目 → 写一章 → 保存 → 重开 | 不提示缺依赖、不白屏、能存能读 | ☐ 待人工 |
