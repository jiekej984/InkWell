### 实现中调整

1. **阵营节点 id 命名空间**：阵营与组织自增 id 都从 1 开始，同图会撞号；`graph_service` 对阵营节点加 `+1_000_000` 偏移，边同步（补测试）。
2. **组织节点人数**：图接口补 `member_count`，组织卡显示「类型 · N 人」。
3. **阵营「N 个组织」**：阵营节点不带分组字段，前端按可见组织统计。
4. **图布局**：
   - 人物：BFS 同心环初始 + 简化 FR（300 轮分帧）+ 节点-连线分离；
   - 阵营：列式分簇（阵营卡在上、组织竖排，相邻列上下错开），不再用圆环；
   - 手动摆位永久优先：有 pinned 的布局不自动重算，只有「重排」覆盖；
   - 布局算法修订号存在 localStorage，旧自动布局升级时重算一次。
5. **无障碍**：关系名直接标在线上（可关闭），不依赖颜色区分关系。
6. **同姓角色**：首字相同的角色节点显示 2~3 字全名，避免只显示一个字认错人。

## 四、偏差与延后

| 项 | 决策 | 归属 |
|---|---|---|
| 组织模式「卧底成员虚线」 | 图接口为组织级，无成员边；卧底身份在角色卡/成员表可查，补边成本高 | V2.1 视需要 |
| 出场检索（FR-8.23） | 任务清单标 P2、可延至 V2.1，本期未做 | V2.1 |
| 组织树 50 节点压测、拖拽帧率采样 | 未单独固化；布局算法为 O(n) 确定性分层，当前无瓶颈 | V2.1 性能回归 |
| 项目软删除不级联 V2 数据 | 角色/组织/阵营不随项目进回收站；项目恢复后原样保留，物理清空时外键级联 | 当前行为，已记录 |
| 图 UX 细节 | 用户反馈的拖拽边界、双击、卡片遮挡、共线、同姓已修；边标签碰撞、社区着色留后续 | V2.1 |
| 导出全图 | 当前导出「当前视口」（所见即所得） | V2.1 可选 |
