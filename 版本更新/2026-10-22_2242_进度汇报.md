## 二、关键决策及其依据

| ID | 决策 | 依据 / 来源 |
|---|---|---|
| **S1-01** | FTS5 分词器采用 **trigram** | SQLite 官方 FTS5 文档 §4.3.1（unicode61 默认类别 `L* N* Co`，连续中文被视为单个 token）与 §4.3.4（trigram 支持通用子串匹配）。**本机实测**：SQLite 3.45.1，unicode61 下 `MATCH '中文'` 命中 0 条；trigram 下 `MATCH '中文测试'` 命中 1 条。unicode61 会导致 FR-7（Must）对中文用户完全不可用 |
| **S1-05** | PRAGMA 在 `connect` 事件中直接执行 | SQLAlchemy 2.0 官方 SQLite 文档示例使用 `dbapi_connection.autocommit = True`，但该属性在 **Python 3.11 的 `sqlite3.Connection` 上不存在**（3.12+ 才提供），照抄会抛 `AttributeError`。**实测**：connect 事件时 `isolation_level == ''`（事务未开启），直接执行 `PRAGMA foreign_keys=ON` 有效（返回 1） |
| **S1-06** | 窗口 `text_select=True`、`private_mode=False` | pywebview 官方 API 默认 `text_select=False`（写作应用必须允许选中文本）、`private_mode=True`（localStorage 不保留，会破坏暂存兜底 AC-4 与「恢复上次项目」）。均实测于 `webview/__init__.py` 签名 |
| 禁调试 | `debug=False` | 核实 `webview/platforms/edgechromium.py` 第 287/288/290 行：`AreBrowserAcceleratorKeysEnabled` / `AreDefaultContextMenusEnabled` / `AreDevToolsEnabled` 均绑定 `_state['debug']` |
| 子线程 uvicorn | 安全 | 核实 `uvicorn/server.py`：`capture_signals()` 在非主线程时直接返回，不注册 signal handler；环境冒烟测试亦已验证 |
| token 注入方式 | `js_api` 而非 URL query | pywebview 官方「Javascript–Python bridge」文档：`js_api` 公有方法映射为 `pywebview.api.*`；且 `pywebview.api` 不保证在 `window.onload` 可用，须订阅 `pywebviewready`。NFR-S2 要求 token 不入 URL |

### 错误码映射补全（S1-02 / S1-03）

报告 §6.1 定义了业务错误码但未规定 HTTP 状态码映射；§6.3 只列了签名/路径/不存在三类失败码，
未覆盖 Host 校验失败。本阶段按「HTTP 承载传输语义、code 承载业务语义」补全：

| 场景 | HTTP | code |
|---|---|---|
| token 无效 / Host 非法 | 401 | 1002 |
| 签名无效或过期 | 401 | 4004 |
| 请求行非法（absolute-form） | 400 | 4003 |
| 其他业务错误 | 200 | 对应 code |
