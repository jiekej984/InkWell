## 二、§6.3 关键接口行为补充

1. **`GET /files/{relpath}?sig=` 校验顺序**：实现为「**路径规范化 → 签名 → 文件存在**」。
   报告原顺序（签名在路径前）会让 `/files/../../inkwell.db` 先报 4004，与回归 13 要求的 4003 冲突。
   失败码：路径非法 4003、签名无效/过期 4004、文件不存在 2001。
2. **回滚 `POST /chapters/{cid}/versions/{vid}/restore`**：先以新修订号把**回滚前**正文存为 `restore` 永久快照，
   再覆盖为目标版本内容；`chapter.version_no` 保持新号（不再二次递增）；返回 `restored_from` / `version_no`。
3. **`chapter.version_no` 语义**：修订号 —— 正文保存 +1；手动/里程碑快照再 +1；回滚再 +1。
   `chapter_version.version_no` = 创建时的修订号（唯一）。
4. **回收站恢复 `POST /trash/{type}/{id}/restore`**：父资源在回收站时**不报错**，返回
   `HTTP 200 + code 0 + data.requires_parent=true` 与 `parent{type,id,title}`；
   前端确认后带 `?with_parent=true` 重试；恢复父资源只恢复**同批次**（`deleted_at` 相同）的级联子项。
5. **导出 `POST /projects/{pid}/export`**：只导出正文（不含设定文档）；输出 `exports/{安全书名}_{时间戳}.{txt|md}`；
   空项目 TXT 仍输出书名/简介/「（暂无正文）」，MD 输出 `## 目录` +「（暂无章节）」。
6. **检索 `GET /search`**：查询词 ≥3 字符走 FTS5 trigram，<3 字符降级 LIKE 并返回 `hint`；
   章节与设定文档分两次查后合并；摘要由服务端生成并 HTML 转义（仅 `<mark>` 受信）。
   响应新增 **`fuzzy`**（是否降级 LIKE）与 **`page_limited`**（分页窗口是否被单侧上限截断）；
   分页窗口 = `page*page_size`，单侧上限 **1000**，超出时 `hint` 明确提示「请加长搜索词」。
7. **备份/恢复**：手动 `inkwell_backup_*`、每日 `inkwell_daily_*`（保留 7 日 + 4 周）、
   迁移前/恢复前备份不自动删；恢复前同步校验（损坏 3001、版本过高 3003、非法名 4003），恢复前先做 prerestore 备份。
8. **日志**：`logs/inkwell-YYYY-MM-DD.log`，单文件 10MB 切分、总量 50MB 删最老；脱敏 token/sig/signature；
   请求日志只记方法/路径（去 query）/状态码/耗时。**#44 正文兜底**：`message` 去 HTML 标签后截 300 字
   （尾部 `…[已截断]`），`content_html` / `content` / `text` 等正文字段整值替换为 `[正文已省略]`，
   `context` 每个值 ≤120 字；前端 `logger.js` 只替换密钥值（保留路径与错误码）。
9. **静态图片**：库内 HTML 只存相对路径 `media/...`；返回详情时临时签名（30 分钟，D-11），前端 20 分钟批量续签。
